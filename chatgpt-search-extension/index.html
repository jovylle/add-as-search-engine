ChatGPT Search

Auto-send prompts + address-bar shortcut for Chromium browsers

⚡
Auto-send: Opens ChatGPT with ?prompt= and submits your question automatically
🔍
Address bar: One-time setup adds shortcut c — type, Tab, ask, Enter
🚀
Quick search: Click the extension icon, type your question, Go
🔒
Direct to ChatGPT: No redirect server. Does not change your default search engine.
Chromium extension for Chrome, Edge, Brave, Opera, and Vivaldi. Browsers block extensions from adding search engines automatically — you paste these values once in settings:
FieldValue
NameChatGPT
Shortcutc
URLhttps://chatgpt.com/?prompt=%s

After setup:

c + Tab + "your question" + Enter

Extension popup

Quick search, copy-paste setup values, and auto-send toggle.

Installation

  1. Download from GitHub or load the extension folder
  2. Open chrome://extensions/ (or your browser's equivalent)
  3. Enable Developer mode → Load unpacked → select chatgpt-search-extension
  4. Open the extension popup → copy setup values → add site search once
  5. Use c + Tab + your question, or quick search from the popup
